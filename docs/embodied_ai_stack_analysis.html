Industrial Embodied AI Stack

工业装备具身智能落地选型分析

面向装载机、挖掘机、四足巡检和移动机器人，推荐采用分层架构： 高层 embodied VLM 负责理解与规划，下游 VLA 或传统控制器负责执行， EMOS/RAI 负责把模型、导航、ROS2、控制和事件恢复串成真实系统。

推荐结论

主运行时优先选择 EMOS

EMOS 更贴近真实机器人任务闭环，尤其是 VLM/VLA 编排、导航、事件恢复、 Web UI、模型服务和硬件适配。RAI 更适合仿真验证、ROS2 agent 研究和 benchmark，可作为辅助方法论。

推荐系统架构

不要让 VLA 一开始裸控工程机械液压动作。先用传统控制器和安全层兜底，再逐步引入局部 VLA。
EMOS Recipe 任务编排、状态机、模型调用、事件恢复、Dashboard。
Embodied VLM Cosmos Reason、RynnBrain、RoboBrain 负责场景理解、规划、风险判断。
结构化计划 目标区域、阶段、轨迹、可操作点、成功条件、重规划条件。
执行层 传统导航、MPC、轨迹跟踪、液压控制，叠加局部 VLA 策略。
安全层 限速、急停、地理围栏、防碰撞、倾覆风险、人工接管。

模型和框架分层

核心原则：慢思考低频运行，动作策略中频运行，控制器高频运行。
层级 代表工作 主要职责 在工业装备中的角色
Embodied VLM / Reasoner Cosmos Reason RynnBrain RoboBrain Robix 理解场景、识别目标区域、做任务拆解、判断失败和风险。 判断料堆、卸料区、人员风险、禁入区、当前作业阶段。
VLA / Action Policy GR00T PI / openpi OpenVLA Cosmos Policy RynnVLA 根据图像、语言、状态输出局部动作或 action chunk。 适合做对准、视觉伺服、异常恢复建议，不建议初期直接裸控液压。

装载机 / 挖掘机落地路线

从低风险感知与编排开始，逐步引入局部策略，最后形成半自动作业闭环。

阶段 1：低风险感知闭环

  • 接入相机、激光、IMU、CAN、液压状态。
  • VLM 做料堆、禁区、人员、车辆、目标区域识别。
  • EMOS 负责任务状态和异常事件。

阶段 2：导航与定点作业

  • 导航到料堆、卸料点、挖掘区或巡检点。
  • 传统控制器负责路径跟踪和安全限速。
  • 模型只做低频规划和重规划。

阶段 3：局部 VLA 策略

  • VLA 做对准料堆、判断铲斗装满、选择重试动作。
  • 动作经过控制器和安全层过滤。
  • 失败时回到 VLM 重新规划。

阶段 4：半自动作业闭环

  • 装载：取料、运输、卸料、复检。
  • 挖掘：定位工作面、挖掘、回转、装车。
  • 保留人工接管和独立安全链路。

最终建议

选型不是模型越端到端越好，而是谁能在真实现场稳定闭环。
主框架 EMOS，用于工业现场任务编排、导航、VLM/VLA 调度、事件恢复和 UI。
辅助参考 RAI / Robotec.ai 方法论，用于仿真验证、数字孪生、SIL/HIL 和 ROS2 agent 工程参考。
上游模型 Cosmos Reason 或 RynnBrain。前者适合 NVIDIA 生态，后者在 grounding、trajectory、affordance 上更直接。
下游执行 传统控制器为主，VLA 为辅。初期不要让 VLA 直接控制装载机/挖掘机全部动作。
POC 周期 6-8 周，从巡检、定点行驶、料堆识别、禁区识别等低风险任务开始。
